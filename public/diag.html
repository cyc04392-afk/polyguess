폴리게스 흰 화면 검사

버튼을 위에서부터 하나씩 눌러 보세요. 게임이 새 탭에서 열려요. 열린 화면이 보라색 게임 화면으로 유지되면 "됨", 잠깐 떴다가 하얗게 변하면 "안 됨"이에요. 각 탭은 10초쯤 그대로 두었다가 닫아 주세요(그동안 화면 상태를 서버에 스스로 보고해요).

  1. 1평소대로 열기아무것도 끄지 않은 보통 상태
  2. 2전부 끄고 열기아래 3~7번을 한꺼번에 끈 상태. 이것도 하얗다면 게임 밖(브라우저·그래픽) 문제
  3. 3고정 배경 끄기보라색 그라데이션·점무늬 대신 단색 배경
  4. 4광고 자리 끄기양옆의 '광고 자리' 상자를 만들지 않음
  5. 5웹 글꼴 끄기구글 글꼴(Jua·Noto Sans KR) 대신 컴퓨터 기본 글꼴
  6. 6서버 연결 끄기게임 서버에 접속하지 않음(참여 버튼은 안 눌림)
  7. 7그림자·효과 끄기그림자·흐림·움직임 효과를 모두 끔

2번도 하얗다면

① 시크릿 창(Ctrl+Shift+N)에서 게임을 열어 보세요. 거기서는 괜찮다면 확장 프로그램(광고 차단 등)이 원인이에요.

② 크롬 오른쪽 위 ⋮ → 설정 → 시스템 → "사용 가능한 경우 그래픽 가속 사용"을 끄고 → 다시 시작. 그 뒤 괜찮다면 그래픽 드라이버 쪽 문제예요.

결과는 /debug에 쌓여요. 어떤 번호가 "됨"·"안 됨"이었는지만 알려 주시면 돼요.
