# 폴리게스 — 글로 적고, 3D로 만들고, 맞혀요

갈틱폰 방식의 3D 파티 게임 웹 프로토타입입니다. 한 사람이 제시어를 적으면 옆 사람이 3D로 만들고,
그다음 사람은 3D만 보고 무엇인지 적고… 모두의 손을 거친 뒤 앨범을 함께 봅니다.
**다같이 맞추기** 모드에서는 한 사람의 3D를 보고 모두가 동시에 정답을 외칩니다.

브라우저만 있으면 되고, 설치 프로그램은 Node.js 하나뿐입니다. 화면은 **한국어·영어·일본어·중국어·프랑스어·독일어** 6개 언어로 나옵니다(오른쪽 위 🌐 버튼).

## 1. 처음 한 번만: Node.js 설치

1. https://nodejs.org 에 들어가서 **LTS** 라고 적힌 큰 버튼을 눌러 내려받습니다.
2. 내려받은 파일을 실행해 "다음"만 눌러 설치합니다. (설정은 바꾸지 않아도 됩니다)

## 2. 게임 켜기

| 운영체제 | 할 일 |
|---|---|
| Windows | 이 폴더의 **`시작.bat`** 을 더블클릭 |
| Mac | 이 폴더의 **`시작.command`** 를 더블클릭 (처음에는 "확인되지 않은 개발자" 경고가 뜰 수 있어요. 파일을 **오른쪽 클릭 → 열기** 로 한 번만 열어 주면 됩니다) |

검은 창이 하나 뜨고(처음엔 필요한 파일을 1분쯤 내려받습니다) 브라우저가 자동으로 열립니다.
브라우저가 안 열리면 주소창에 **http://localhost:8080** 을 적어 주세요.

> 검은 창은 게임 서버예요. **창을 닫으면 게임이 꺼집니다.** 다 놀고 나서 닫으세요.

## 3. 친구 초대하기

- **같은 와이파이**에 있는 친구: 방에 들어가서 **🔗 초대** 버튼을 누르면 링크가 복사됩니다. 링크의 `localhost` 부분을
  내 컴퓨터 IP 주소(예: `192.168.0.12`)로 바꿔서 보내 주세요. (Windows: 검은 창에 `ipconfig`, Mac: 시스템 설정 → 네트워크에서 확인)
- **멀리 있는 친구**: 인터넷에 서버를 올려야 합니다. 이 폴더를 그대로 Render / Railway / Fly.io 같은 Node.js 호스팅에 올리면 됩니다
  (시작 명령 `npm start`, 포트는 환경 변수 `PORT` 를 그대로 씁니다). 임시로는 `ngrok http 8080` 같은 터널 프로그램으로도 됩니다.

## 4. 노는 법

1. 닉네임을 적고 **시작** → 방이 만들어집니다. 3명 이상(다같이 맞추기는 2명 이상) 모이면 방장이 **시작**을 누릅니다.
2. **사전 설정** 탭에서 놀이 방식을 고릅니다. 세세하게 바꾸려면 **커스텀 설정** 탭.
3. 라운드마다 **글 쓰기 ↔ 3D 만들기**가 번갈아 옵니다. 다 했으면 **완료**. 마음이 바뀌면 **수정하기**.
4. 마지막에 **앨범**을 방장이 한 장면씩 넘기며 다 같이 봅니다. 3D 장면은 갈틱폰처럼 **만드는 과정이 타임랩스로** 빈 바닥에서 완성까지 쭉 재생된 뒤 멈추고(약 6초), **🔁 과정 다시 보기**로 다시 볼 수 있습니다. 다같이 맞추기에서는 정답이 공개된 뒤에 재생됩니다. 마음에 드는 3D에는 **👍 따봉**을 누를 수 있고(내 작품은 못 누름), 받은 따봉 수는 대기실 명단·점수판·최종 점수에 사람마다 표시됩니다. **📷** 를 누르면 그 장면을 그림 파일로 저장합니다.
5. 대기실에서는 **🚪 나가기**로 방을 나와 다른 방에 들어갈 수 있습니다.
6. **언어**: 오른쪽 위 **🌐 지구본** 버튼으로 한국어·English·日本語·中文·Français·Deutsch 를 고를 수 있습니다. 처음 열면 브라우저 언어를 따라가고, 한 번 고르면 그 브라우저에 기억됩니다. 주소 뒤에 `?lang=en` 처럼 붙여 보내면 그 언어로 열립니다(예: `https://polyguess.onrender.com/?lang=ja`). 같은 방에 다른 언어 사람이 섞여도 각자 자기 언어로 보이고, **제시어 추천과 시간 초과 때 채워지는 글은 방장의 언어**를 따릅니다.

### 3D 만들기 도구 (글씨 없이, 그림 버튼으로)

갈틱폰 그리기 화면과 같은 배치예요. 버튼에 마우스를 올리면 짧은 설명이 뜨고, 오른쪽 아래 **?** (또는 F1) 를 누르면 전체 설명이 나와요.

| 어디 | 무엇 |
|---|---|
| 왼쪽 | 색 18가지(누르면 선택한 도형에 바로 적용), 재질 5가지(기본·반짝·금속·유리·빛남을 작은 공 그림으로) |
| 노트 왼쪽 위 | **물체(Tab) · 점(1) · 선(2) · 면(3)** — 도형 하나를 고르고 1·2·3을 누르면 그 도형의 꼭짓점·모서리·면을 고르는 편집 모드가 켜져요. 켜진 칸이 하얗게 표시돼요 |
| 노트 오른쪽 위 | **📷 스크린샷**(지금 보이는 장면을 PNG로 저장) · **조작 모드**(기본 / Blender / Maya / 3ds Max / ZBrush — 마우스·단축키가 그 프로그램처럼 바뀌어요) |
| 아래 | 도형 14가지가 **실제 3D 모양 그림**으로 — 누르면 바닥에 놓이고 바로 옮길 수 있어요. 그 위 줄에는 상황에 맞는 조절이 나와요: 찰흙 붓 5가지와 크기·세기·좌우 대칭 / 베벨·루프 자르기·밀어내기의 폭·개수·거리와 ✓ ✕ / 광원의 종류·세기·각도·높이·방향 |
| 오른쪽 | 선택 · 이동 · 회전 · 크기 · 찰흙 · **페인트**(면 색칠) · 격자 맞추기 · **점·선·면 편집** · **베벨**(모서리 깎기) · **루프 자르기**(한 바퀴 선 넣기, 개수·위치 조절) · **밀어내기** · **인셋**(면 테두리 안으로 모으기) · 복제(**제자리에**) · 좌우 뒤집어 복제 · 바닥에 붙이기 · 삭제 · **광원**(해·전구·스포트) · 배경 바꾸기 · 도움말 |

- 베벨·밀어내기·인셋은 **블렌더처럼** 시작한 뒤 마우스를 움직여 양을 정하고 왼쪽 클릭으로 확정해요(오른쪽 클릭·Esc 취소). 아래 줄 슬라이더로 정확히 맞출 수도 있어요.
- **베벨**(Ctrl+B): 선(또는 점·면)을 고르고 → 마우스를 멀리 움직이면 넓어지고, 휠로 둥글기 단계 → 클릭.
- **루프 자르기**: 버튼을 누르고 도형의 모서리에 마우스를 올리면 한 바퀴 노란 선이 미리 보여요. 휠(또는 −/+)로 개수를 정하고 클릭 → 좌우로 움직여 위치를 정하고 다시 클릭.
- **밀어내기**(Ctrl+E): 면을 고르고 → 면이 향하는 쪽으로 마우스를 움직이면 튀어나오고 반대면 들어가요 → 클릭.
- **인셋**(Ctrl+I): 면을 고르고 → 면 가운데 쪽으로 마우스를 움직이면 두꺼워져요 → 클릭. 작업 중 Ctrl+I 를 다시 누르면 '면마다 따로'. 깊이(음수면 안으로 파임)는 아래 줄에서. 밀어내기와 인셋은 면을 고른 뒤에만 돼요(실수로 전체에 적용되지 않게).
- **페인트**(P): 왼쪽에서 색을 고르고 물체의 면을 클릭하거나 문질러요. 아래 줄에서 붓 크기(맨 왼쪽은 면 하나씩)·지우개·전체 칠하기·칠한 색 지우기. 찰흙(T)을 한 번 켜서 촘촘하게 만든 물체는 더 곱게 칠할 수 있어요. 칠한 색은 작품에 저장되고 앨범·맞추기 화면에도 그대로 보여요.
- **광원**: 버튼을 누르면 해가 하나 들어와요. 회전 도구로 돌리거나 아래 줄의 높이·방향 슬라이더로 빛 각도를 바꿔요. 광원을 넣으면 기본 햇빛은 약해져서 내 광원이 잘 보여요. 최대 4개.
- **크기 조절**: 네모 손잡이를 끄는 만큼만 바뀌어요(가운데는 전체). Shift 를 누르면 아주 조금씩.
- **복제 / 복사·붙여넣기**: 복제(Ctrl+D)와 Ctrl+C → Ctrl+V 모두 **제자리에** 겹쳐 만들어지고 그것이 선택된 상태라 바로 옮기면 돼요.
- **되돌리기**: Ctrl+Z, 다시 하기 Ctrl+Y 또는 Ctrl+Shift+Z (화면 버튼은 없어요).

## 5. 설정 항목

- **모드**: 릴레이(글→3D→글→…, 앨범 공개) / 다같이 맞추기(글→3D 한 번, 그다음 모두가 동시에 맞추기)
- **시간**: 빠른 선택(빠름·보통·느긋하게·다이나믹)을 누르거나, **글 쓰기 / 3D 만들기 / 맞추기 시간을 초 단위로 직접** 정해요(10초~10분). "과반이 끝내면 15초 카운트다운" 스위치도 따로 켤 수 있어요
- **턴**: 앨범 하나가 몇 명의 손을 거칠지(전원 또는 2~8턴). 인원이 많을 때 짧게 끝내는 용도
- **만드는 사람**(다같이 맞추기): 제시어를 낸 사람이 직접 3D로 만들지(켜짐), 다음 사람이 만들지(꺼짐). 제시어를 낸 사람과 만든 사람은 맞추기에 참여하지 않아요. 2명일 때는 항상 직접 만들어요
- **점수판**: 다같이 맞추기에서 옆에 순위를 보여줄지
- **최대 인원**: 2~14명 (릴레이는 3명부터 시작할 수 있어요)

다같이 맞추기 점수: 먼저 맞힌 사람 3점, 그 뒤에 맞힌 사람 1점, 작품을 만든 사람 2점, 제시어를 낸 사람 1점(직접 만든 경우에는 2점만).
띄어쓰기·문장부호가 달라도 글자가 같으면 자동 정답이고, 뜻만 맞는 답은 제시어를 낸 사람이 ✓로 인정합니다.

## 6. 개발자용

```
npm install      # 처음 한 번
npm start        # http://localhost:8080
npm test         # 규칙·저장 포맷·서버 상태 머신·번역 사전 단위 테스트
```

- `server.js` 정적 파일 + WebSocket. `server/game.js` 방 하나의 상태 머신(네트워크와 분리, 테스트 가능).
- `shared/rules.js` 게임 규칙, `shared/scene.js` 3D 작품 저장 포맷과 검증 — 둘 다 DOM/렌더러에 의존하지 않아 다른 엔진(유니티 등)으로 옮길 때 그대로 규격서가 됩니다.
- `shared/polymesh.js` 다각형 메시(점·면 목록, 렌더용 삼각형화, 저장 포맷), `shared/primitives.js` 기본 도형 14종, `shared/meshops.js` 베벨·루프 자르기·밀어내기·인셋·삭제, `shared/paint.js` 면 색칠 데이터, `shared/timelapse.js` 만드는 과정(타임랩스) 차이 목록·한도·검증 — 전부 순수 JS라 서버 검증과 테스트에 그대로 쓴다.
- `public/js/editor.js` 3D 만들기 도구(Three.js), `editmode.js` 점·선·면 편집, `camera.js` 조작 모드별 카메라, `schemes.js` 모드별 마우스·단축키 표, `lights.js` 광원, `sculpt.js` 찰흙, `shapes.js` 도형↔지오메트리, `sceneio.js` 저장/불러오기·재질·배경, `editorui.js` 도구 화면(아이콘), `icons.js` 아이콘, `thumbs.js` 도형 그림 렌더링, `viewer.js` 읽기 전용 뷰어, `ads.js` 광고 자리, `main.js` 게임 화면.
- 번역: `shared/i18n.js` 가 언어 고르기(`?lang` → 저장값 → 브라우저 언어 → 한국어)와 `t('한국어 원문', {자리표})` 를 맡고, 사전은 `shared/lang/en.js`·`ja.js`·`zh.js`·`fr.js`·`de.js`(키는 한국어 원문 그대로). 글자를 새로 넣을 때는 코드에 한국어로 쓰고 `tr()`/`t()` 로 감싼 뒤(정적 HTML 은 `data-i18n` 속성) 다섯 사전에 줄을 추가합니다. `node scripts/i18n-keys.js` 가 코드의 한국어 글자를 전부 뽑아 주고, `npm test` 의 `test/i18n.test.js` 가 빠진 키·남는 키·자리표 불일치·번역 틀 밖의 한글을 잡아냅니다. 언어를 하나 더 붙이려면 `shared/lang/<code>.js` 를 만들고 `shared/i18n.js` 의 `LANGS`·`DICTS` 에 한 줄씩 추가하면 됩니다.
- 메시지 규격과 작품 포맷: `docs/PROTOCOL.md`
- `public/demo.html` 은 서버 없이 3D 만들기 도구만 체험하는 페이지(정적 호스팅 가능).

같은 와이파이가 아닌 친구와 하려면 서버가 인터넷에 있어야 합니다. 무료로 올릴 수 있는 곳(Render) 기준으로 적었어요. 터미널은 필요 없습니다.

1. **GitHub 계정** 만들기 → 오른쪽 위 **+ → New repository** → 이름 `polyguess`, Public 또는 Private → Create.
2. 만들어진 빈 저장소 화면에서 **uploading an existing file** 링크를 누르고, 이 폴더 안의 파일을 **전부 끌어다 놓기**(`node_modules` 폴더와 `screenshots` 폴더는 빼도 됩니다) → **Commit changes**.
3. **Render(render.com) 계정** 만들기(GitHub 로 가입) → **New → Blueprint** → 방금 만든 저장소 선택 → **Apply**. 이 폴더의 `render.yaml` 대로 서버가 만들어집니다. (또는 **New → Web Service** 에서 저장소를 고르고 Build `npm ci`, Start `node server.js` 로 적어도 됩니다.)
4. 몇 분 뒤 `https://polyguess-xxxx.onrender.com` 같은 주소가 나옵니다. 이 주소가 게임 주소예요. 친구에게 보내면 됩니다.

- 무료 요금제는 15분 동안 아무도 안 들어오면 잠들었다가 첫 접속 때 30초~1분 정도 걸려 깨어납니다.
- Railway, Fly.io, Koyeb 처럼 Node.js 나 Docker(`Dockerfile` 포함) 를 받아 주는 곳이면 어디든 같은 방법으로 올릴 수 있습니다. 포트는 `PORT` 환경 변수를 따릅니다.
- 코드를 고친 뒤에는 GitHub 에 파일을 다시 올리면(덮어쓰기) Render 가 자동으로 새로 배포합니다.

## 8. 광고 넣기 (구글 애드센스)

광고 자리는 이미 달려 있습니다. 1100px 이상 화면에서는 **모든 화면의 양옆에 세로 배너**(160×600, 1500px 미만 화면은 120×600), 그보다 좁은 폰·태블릿에서는 **아래 가로 배너**가 나옵니다. 번호를 적기 전에는 점선으로 **광고 자리**만 보입니다(`public/ads.config.js` 에서 `showPlaceholders: false` 로 바꾸면 그것도 숨김, `enabled: false` 면 광고 기능 전체 끔).

애드센스 계정은 **사이트 주인이 직접** 만들어야 합니다(구글 로그인, 본인 확인, 나중에 우편으로 오는 PIN 주소 인증). 그리고 `polyguess.onrender.com` 처럼 **남의 도메인 아래 주소는 애드센스에 사이트로 등록할 수 없어서**, 내 도메인이 먼저 필요합니다.

1. **도메인 사기**: 가비아·호스팅케이알·Cloudflare 등에서 원하는 주소(예: `polyguess.kr`)를 삽니다(1년에 1~2만 원).
2. **Render 에 도메인 연결**: Render 대시보드 → polyguess → **Settings → Custom Domains → Add** 에 도메인을 적으면 DNS 레코드(CNAME 또는 A)를 알려 줍니다. 그 값을 도메인 산 곳의 DNS 설정에 그대로 넣습니다. 몇 분~몇 시간 뒤 그 주소로 게임이 열립니다(https 자동).
3. **애드센스 신청**: adsense.google.com → 계정 만들기 → 사이트에 그 도메인 등록 → "사이트 확인" 단계에서 `ca-pub-…` 로 시작하는 게시자 ID를 `public/ads.config.js` 의 `client` 에 적고 GitHub 에 올립니다. 그러면 서버가 자동으로 애드센스 코드를 페이지 머리글에 넣고 `/ads.txt` 도 만들어 주므로, 애드센스의 "코드 스니펫"·"ads.txt" 확인 방법 중 아무거나 통과합니다. 심사는 며칠~몇 주 걸리고, 심사 중에는 광고가 안 나옵니다.
4. **승인 뒤 광고 단위 3개 만들기**: 디스플레이 광고로 왼쪽 세로·오른쪽 세로·아래 가로 하나씩. 각 단위의 슬롯 번호(숫자 10자리)를 `public/ads.config.js` 의 `slots` left/right/bottom 에 따옴표 안에 적고 GitHub 에 올리면 광고가 나옵니다.
